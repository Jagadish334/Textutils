# 📝 TextUtils

TextUtils is a simple and responsive React.js web application built with **React.js** and **Bootstrap 5**. It provides a variety of text manipulation and analysis features, allowing users to quickly edit, format, and analyze text with an intuitive user interface.

---

## 🚀 Features

- 🔠 Convert text to Uppercase
- 🔡 Convert text to Lowercase
- ✨ Capitalize the first letter of every word
- 🔄 Replace words or phrases
- ↩️ Reverse text
- 🧹 Remove extra spaces
- 📋 Copy text to clipboard
- 📥 Download text as a `.txt` file
- 🗑️ Clear text
- 📊 Word count
- 🔢 Character count
- ⏱️ Estimated reading time
- 👀 Live text preview
- 🌙 Light/Dark Mode
- 🚨 Bootstrap alert notifications

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Jagadish334/Textutils.git
```

Navigate to the project

```bash
cd Textutils
```

Install dependencies

```bash
npm install
```

Start the application

```bash
npm start
```

Open your browser and visit:

```
http://localhost:3000
```
